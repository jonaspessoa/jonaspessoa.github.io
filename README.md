## Executar localmente

Site estático em HTML e CSS, sem dependências ou credenciais.

```bash
git clone https://github.com/jonaspessoa/jonaspessoa.github.io.git
cd jonaspessoa.github.io
python -m http.server 4174 --bind 127.0.0.1
```

Requer Python 3. Abra [http://127.0.0.1:4174/](http://127.0.0.1:4174/).

## Estrutura e publicação

- `index.html`: conteúdo e projetos selecionados.
- `style.css`: identidade visual e responsividade.
- `assets/`: capturas de demos com dados fictícios e ilustrações identificadas.

O GitHub Pages publica `main`, pasta `/ (root)`. O repositório tem o mesmo nome do domínio da conta: o portfólio é publicado diretamente em `https://jonaspessoa.github.io/`, sem subpasta de projeto.

## Origem das imagens e escopo

CFIC, EduCore e Contratos usam capturas reais de ambientes demonstrativos revisados. O WinSIGAA usa ilustrações SVG identificadas como tal. Os números são retratos das capturas. Arquivos visuais anteriores foram preservados.

Os repositórios operacionais, dados institucionais e credenciais não fazem parte do portfólio. Stack, fluxos e limites são detalhados nos showcases de cada projeto; o site não promete homologação de produção.

Revisado em **05/11/2026**. Marca e imagens institucionais pertencem aos respectivos titulares.
