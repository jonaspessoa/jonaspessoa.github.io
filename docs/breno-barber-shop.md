# Breno Barber Shop — apresentação do projeto

**Projeto de experiência web para uma barbearia.**

[Voltar ao portfólio](https://jonaspessoa.github.io/)

**[Abrir prévia de desenvolvimento](https://breno-barber-shop-previa.vercel.app/)** — versão para avaliação; não é o site final nem indica aprovação do cliente.

## Objetivo
Apresentar a barbearia, seus serviços e o trabalho visual de forma clara em dispositivos móveis e desktops, com uma navegação que ajude o visitante a encontrar informações e entrar em contato.

## Abordagem
- Interface responsiva e foco na apresentação dos serviços.
- Componentes interativos com React e Framer Motion.
- Processo de build com esbuild para os componentes interativos.
- Organização de arquivos estáticos e recursos visuais para publicação.

## Tecnologias identificadas
React 19, React DOM, Framer Motion e esbuild.

## Estado e acesso
O código de desenvolvimento está em repositório privado. Esta página documenta a proposta e a stack identificada, **não** representa uma entrega final homologada ou confirmação de funcionalidades não verificadas.
